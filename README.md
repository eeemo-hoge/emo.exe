## ✨ Concept

**emo.exe** は、  
横に流れていくような、自分だけの対話プロンプトのための小さな場所です。

昨日までの自分をなぞるためではなく、  
**今日から先の気分と言葉**を、少しだけファンシーに起動するためにあります。

> “I wanted to write my own prompt.”
